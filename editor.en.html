How to edit the site: step-by-step guide ↗

Change the content below. Preview and export the content.js file to update the site on GitHub.

How to publish changes
  1. Edit the fields and click Export content.js.
  2. Open the repository on GitHub ↗ with an account that has write access.
  3. Upload the file to the root folder, replacing the existing file, and confirm with Commit changes.

Changes stay in your browser until you upload the file to GitHub. This editor does not grant repository write access. Covers must be uploaded to assets/. To add photographs to an album, upload them to assets/albums/album-name/, using the folder name in its record. Album images are detected automatically during publication.
