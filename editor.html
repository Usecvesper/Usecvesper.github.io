Como editar o site: guia passo a passo ↗

Altera o conteúdo nos campos abaixo. Pré-visualiza e exporta o ficheiro content.js para atualizar o site no GitHub.

Como publicar as alterações
  1. Edita os campos e clica em Exportar content.js.
  2. Abre o repositório no GitHub ↗ com uma conta com acesso de escrita.
  3. Carrega o ficheiro na pasta principal, substituindo o existente, e confirma em Commit changes.

As alterações ficam apenas no teu navegador até carregares o ficheiro no GitHub. Este editor não dá acesso de escrita ao repositório. As capas devem ser carregadas em assets/. Para adicionar fotografias a um álbum, carrega-as em assets/albums/nome-do-album/, usando o nome de pasta indicado no registo. As imagens desse álbum são detetadas automaticamente na publicação.
