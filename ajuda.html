GESTÃO DO SITEGUIA DA EQUIPA

O site também é teu.

Textos, personagens e fotografias: podes atualizar tudo sem programar.

Abrir editor de conteúdo ↗Abrir repositório ↗
01 / TEXTOS E INFORMAÇÃO

Editar, pré-visualizar, publicar.

  1. Abre o editor de conteúdo.
  2. Altera os campos: apresentação, contactos, recrutamento, história, membros, perguntas, álbuns, histórico da unidade ou transmissões. Preenche também os campos (EN) para a versão inglesa.
  3. Clica em Pré-visualizar. A cópia aberta mostra as tuas alterações, sem mudar o site público.
  4. Clica em Exportar content.js. O navegador transfere um ficheiro.
  5. No repositório, escolhe Add file → Upload files na pasta principal. Arrasta o novo content.js e confirma em Commit changes.
  6. A publicação começa automaticamente. Espera que a execução mais recente em Actions fique verde; depois atualiza o site.

Editar os campos ou guardar um rascunho não altera o site público. A publicação acontece quando carregas o ficheiro no GitHub.

02 / MEMBROS

Uma ficha para cada pessoa.

No editor, abre Membros e seleciona uma ficha. Altera o nome/callsign, título, origem, função e biografia. Os botões Subir e Descer definem a ordem. Usa Adicionar para novas pessoas.

Cada ficha tem campos em português e inglês. Preenche ambos para manter os dois lados do arquivo atualizados. Callsigns e caminhos das fotografias são partilhados entre idiomas.

Para a fotografia do membro 8, carrega uma imagem em assets/, por exemplo member-8.jpg. Na ficha, troca o campo Fotografia por assets/member-8.jpg. Exporta e publica o novo content.js. A imagem provisória fica disponível em assets/member-placeholder.svg.

Os caminhos distinguem maiúsculas de minúsculas: DSC_0792.JPG e dsc_0792.jpg são nomes diferentes. Copia o nome exato do ficheiro.

03 / FOTOGRAFIAS

Carregar imagens no álbum certo.

  1. Abre assets/albums no GitHub.
  2. Entra na pasta do jogo. O nome da pasta também aparece no editor, no registo do álbum.
  3. Escolhe Add file → Upload files, arrasta as fotografias e confirma Commit changes.

As imagens são detetadas na publicação. Não precisas de registar cada fotografia no editor. A ordem segue os nomes dos ficheiros; usa 001.jpg, 002.jpg, etc. para controlar a sequência. Aceita JPG, JPEG, PNG, WebP, AVIF e GIF.

Para adicionar fotografias a um álbum existente, não precisas de exportar content.js. Basta carregá-las na respetiva pasta.

04 / UM NOVO JOGO

Criar um álbum.

  1. No editor, abre Fotografias → Adicionar.
  2. Preenche o título e a legenda, com uma data e ano. Exemplo: Souselas · 18/10/2026.
  3. Em Nome da pasta do álbum, escreve um nome único, sem espaços: osot-18-10-2026.
  4. Carrega as imagens no GitHub em assets/albums/osot-18-10-2026/. Podes arrastar a pasta a partir de assets/albums, ou criar primeiro um ficheiro .gitkeep nesse caminho.
  5. Em Fotografia, indica a capa: por exemplo assets/albums/osot-18-10-2026/001.jpg.
  6. Exporta o content.js e publica-o na pasta principal do repositório.
05 / RASCUNHOS E RECUPERAÇÃO

Guarda o que ainda está em curso.

Guardar rascunho mantém as alterações só nesse navegador. Recuperar rascunho volta a abri-las. Cópia JSON transfere uma cópia para o teu computador; recupera-a com Importar JSON.

O editor é público, mas só uma conta com permissão de escrita no GitHub pode publicar. Não coloques dados privados ou palavras-passe nos campos. Se precisares de recuperar uma versão publicada, o histórico dos commits está no repositório.

O aspeto e a estrutura do site estão nos ficheiros HTML/CSS. Para mudanças de design, podes continuar a pedir-me alterações. O editor cobre o conteúdo, os contactos, os membros, a história da unidade, os antigos membros, as transmissões e os álbuns. Os campos (PT) e (EN) controlam cada tradução.
