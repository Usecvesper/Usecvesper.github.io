SITE MANAGEMENTUNIT GUIDE

Make the site your own.

Edit text, dossiers, translations and photographs without programming.

Open the content editor ↗Open the repository ↗
01 / CONTENT AND LANGUAGES

Edit. Preview. Publish.

  1. Open the content editor. Portuguese and English fields are shown together; English fields end in (EN).
  2. Change the introduction, contacts, recruitment, story, operators, FAQs, albums, history chapters or transmissions.
  3. Select Preview to see the draft. Use the PT/ENG button to check both languages.
  4. Select Export content.js to download the updated file.
  5. At the root of the GitHub repository, select Add file → Upload files, upload content.js and confirm Commit changes.
  6. Wait for the latest publication in Actions to turn green, then refresh the site.

Editing or saving a draft does not change the public website. Uploading content.js to GitHub publishes it.

02 / OPERATORS

Update a dossier.

Under Operators, expand a record and edit the callsign, title, origin, role and biography. Fill in its English fields too. Move up and Move down set the order. Add creates a new operator.

Upload a portrait to assets/, then enter its exact path in the Photograph field. Example: assets/member-8.jpg. The placeholder is assets/member-placeholder.svg. Export and publish content.js after changing the path.

Paths are case-sensitive. DSC_0792.JPG and dsc_0792.jpg are different filenames. Copy the exact name from GitHub.

03 / PHOTOGRAPHS

Add images to an existing album.

  1. Open assets/albums on GitHub.
  2. Enter the correct album folder. Its name is also shown in the editor.
  3. Select Add file → Upload files, add your photographs and confirm Commit changes.

The publication detects the images automatically. Filenames set the order; use 001.jpg, 002.jpg and so on if needed. Supported formats: JPG, JPEG, PNG, WebP, AVIF and GIF.

Adding images to an existing album does not require exporting content.js.

04 / NEW ALBUMS

Create a field record.

  1. Under Photographs in the editor, select Add.
  2. Fill in the title and caption in Portuguese and English. Include a year in the caption for the year filters.
  3. Set a unique folder name without spaces, for example osot-18-10-2026.
  4. Upload the photographs under assets/albums/osot-18-10-2026/.
  5. Set the cover image path, for example assets/albums/osot-18-10-2026/001.jpg.
  6. Export content.js and upload it to the repository root.
05 / ARCHIVE AND TRANSLATIONS

Keep both copies of the archive current.

The editor includes the unit story, history chapters, former members and transmissions. Each story field has a Portuguese and an English version. Callsigns, image paths and album folder names are shared between languages.

PT/ENG keeps visitors on the same page and preserves the currently open album. Portuguese is the default when opening the main site.

06 / BACKUPS

Keep a draft.

Save draft stores work in this browser. Restore draft retrieves it. JSON backup downloads a portable copy; load it with Import JSON.

The editor is public, but only an account with repository write permission can publish. Keep private information and passwords out of this public project. Earlier published files can be recovered from GitHub commit history.

The editor controls content. Layout and styling live in the HTML and CSS files. For design changes, you can ask me to update those.
